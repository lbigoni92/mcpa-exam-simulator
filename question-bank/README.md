# Question bank (Fase 2 — vuoto)

Qui verranno generate le domande d'esame originali.

- `question.schema.json` — formato di ogni domanda (JSON Schema 2020-12).
- `per-dominio/D1.json … D5.json` — quiz per singolo dominio (array di domande).
- `simulazioni/sim-XX.json` — simulazioni complete a tempo, distribuite secondo i pesi (vedi `knowledge/manifest.json` → `distribution_example`).

Regole: vedi `knowledge/manifest.json` → `question_generation_rules`. Nessuna domanda reale o dump.
